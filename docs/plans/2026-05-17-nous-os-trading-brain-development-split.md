# NOUS OS / Trading Brain Development Split Decision

> Date: 2026-05-17
> Status: accepted direction

## Decision

NOUS OS and trading-agent should develop as two connected but distinct tracks.

```text
NOUS OS = cognitive protocol / research harness
trading-agent = high-stakes applied proof loop
```

NOUS OS defines the human-AI co-evolution protocol, research language, memory philosophy, anti-sycophancy principles, and evaluation criteria.

Trading Brain / trading-agent validates those principles in a high-constraint investment decision environment where evidence, outcomes, human authority, and capital boundaries matter.

The operator can open the cockpit and see the top review items without being pushed into an unverified capital action.

## Shared operating principle

The two tracks should feed each other:

```text
NOUS OS research principle
  -> Trading Brain high-constraint gate
  -> outcome / review evidence
  -> NOUS OS theory and protocol update
```

NOUS OS should not become infra for its own sake. Trading Brain should not become autonomous trading for its own sake.

Both are successful only if the human-agent pair becomes wiser, more capable, more reflective, and more responsible over time.
