# NOUS OS Cognitive COO One-Pager

## Positioning

NOUS OS is the Cognitive COO Operating System for human-AI co-evolution.

It connects human intent, verified memory, event-driven coordination, domain runtimes, measured outcomes, and human authority into a repeatable operating loop.

## One Line

```text
NOUS OS = Obsidian knowledge sedimentation + verified memory + event mesh + domain runtime + outcome proof + human authority.
```

## System Map

```text
Human intent
  -> Hermes / Aria: COO control plane
  -> Obsidian: human-readable knowledge sedimentation
  -> TrustMem: trustworthy hippocampus
  -> Synapse: event-driven service mesh
  -> Domain runtime: first proof = Trading Brain / trading-agent
  -> Outcome proof: scorecards, reviews, learning updates
  -> Next cycle: better judgment with human authority preserved
```

## Product Boundaries

- TrustMem: agents' trustworthy hippocampus for memory, trust, decay, and verification.
- Obsidian: human-readable knowledge sedimentation layer for North Stars, playbooks, architecture maps, handoffs, reviews, and durable judgment.
- Synapse: event-driven service mesh for agents, DAGs, workers, and budget routing.
- Trading Brain: first vertical proof, a Personal AI Trading COO built on NOUS OS.
- Dashboard / Obsidian / CLI: review surfaces, not live state sources of truth.

## CLS v2

NOUS OS V2 uses CLS v2 to measure whether the loop actually improves:

```text
CLS = 0.35 * outcome_quality_delta
    + 0.20 * correction_absorption
    + 0.15 * memory_reuse_precision
    + 0.15 * repeatability_gain
    + 0.10 * boundary_integrity
    + 0.05 * human_agency_preservation
```

Meaning:

- Measure outcomes, not just output volume.
- Prove human corrections affect future behavior.
- Reward precise memory reuse, not noisy recall.
- Preserve human authority at irreversible boundaries.

## What NOUS OS Is Not

NOUS OS is not a fully autonomous trading system. It does not replace human judgment, bypass broker/risk/reconciliation gates, treat demo scores as production evaluators, or claim to be a production-ready multi-tenant SaaS.
